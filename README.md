# Dive Local

A WIY concept website for a local scuba-diving support/donation platform.

## Files
- `index.html` — website structure
- `style.css` — visual design
- `script.js` — navigation and prototype donation interaction
- `assets/fins-beach.jpg` — user-provided reference photo used in the hero

## Concept
The production business model would connect divers with participating local dive shops and route secure contributions to verified recipient accounts.

The current donation flow is a front-end prototype only. No payment is processed.

## Next development steps
1. Replace prototype shop listings with participating shops.
2. Add verified shop profiles and recipient onboarding.
3. Connect Stripe/Square or another payment processor.
4. Add donation receipts and transaction tracking.
5. Decide the platform's revenue model.
6. Add a real location/search system.
7. Link the finished concept into the Redeemed Roasters site as another WIY portfolio project.

## Current Central Virginia examples
The prototype includes The Dive Shop, Get Down Scuba, and Tri-City SCUBA as local-market examples. Verify participation and recipient details before any production use.
